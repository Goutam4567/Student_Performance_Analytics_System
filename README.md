# Student Performance Analytics System

## Project Overview
The Student Performance Analytics System analyzes students' academic performance using Python.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Google Colab

## Features
- Displays student records.
- Calculates average, maximum and minimum marks.
- Analyzes student performance.
- Generates graphical representations of marks.
- Saves analysis results.

## Project Files
- main.py: Main Python program.
- Student_Performance_Analytics.ipynb: Google Colab notebook.
- students.csv: Student dataset.
- Project_Documentation.pdf: Project report.

## How to Run
1. Install Python.
2. Install the required libraries:
   pip install numpy pandas matplotlib
3. Keep main.py and students.csv in the same folder.
4. Run the program:
   python main.py
